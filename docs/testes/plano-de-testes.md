# Identificação
- **Projeto:** Laravel dieta e treino API
- **Versão do Plano:** 0.1

# Introdução

Este plano de teste define a estratégia, os casos de teste, os recursos necessários e os critérios de aceitação para validação da API.

# Objetivos

- Identificar falhas;
- Validar fluxos críticos;
- Atender aos [requisitos funcionais](/docs/requisitos-regras_de_negocio.md);
- Garantir a segurança e confiabilidade da API;

# Estratégia

- **Nivel de Teste:** Unitário, Integração e Funcional;
- **Tipos de Teste:**
  - Caixa de vidro;
  - Caixa preta;
  - Teste de usabilidade;
  - Teste de segurança;
- **Ferramentas:**
  - Postman;
  - PHPUnit;
  
# Casos de Testes

- [Cadastro de Usuário (CT-U)](casos_teste/cadastro_de_usuario.md)
- [Login do Usuário (CT-L)](casos_teste/login_usuario.md)

# Critérios de Aceitação

- 80% de cobertura de teste;
